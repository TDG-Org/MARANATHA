# /audio — drop-in sound guide

Sounds are sorted into folders. **Drop a correctly-named file in the right folder, then flip that
key's `available` to `true` in `src/data/audioManifest.js` — reload, and it plays.**
`.mp3` preferred (`.ogg`/`.webm` also work). Keys the game calls stay stable; the loader maps them
to these paths.

> This used to say "no code editing", and that was never true: every fetch path in
> `AudioSystem.js` is gated on `available`, so a file nobody flagged is never even requested —
> it just keeps playing the procedural fallback, silently, exactly as if the file were missing.
> The flag exists so the game makes **zero 404 requests** for sounds that have not arrived yet.

```
audio/
  music/     looping score (crossfaded by story mood)
  ambient/   looping background beds (wind, fire, flock)
  sfx/       one-shot effects
  vo/        narrator verse recordings (optional — see bottom)
```

### Music rule

Only one looping score bed may own a story moment. Mood changes crossfade through
the scene music state; they never stack two music tracks. `dark_amb.mp3` is a
reusable dark bed, not a betrayal-only asset.

## Narrator voice — `audio/vo/` (GENERATED — no recording needed)
Every narrator line ships as a real mp3 in here, generated by **`npm run vo`** with ONE neural
storyteller voice (en-US-AndrewNeural, 24kHz 48k mono) — the identical voice on every device.
The lines come straight from `src/data/versesWEB.js`, so if a verse is ever edited, rerun
`npm run vo` and the audio matches the text again. Runtime falls back to a pinned en-US system
voice only if a file is missing. **Don't hand-drop files here** — a later `npm run vo` would
overwrite them (if you ever want custom recordings instead, say so and we'll pin them).

> ⚠ **Note on the dream music:** the narrator itself never changes voice (verified in code — one
> locked voice for the whole game, no separate voice files). If you hear a *different voice* during
> the dream, it's inside `music/dream_wonder.mp3` (that track may contain vocals). Swap it for an
> instrumental dream track and the extra voice is gone.
